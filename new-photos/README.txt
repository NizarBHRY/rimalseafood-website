DROP NEW PHOTOS HERE
====================

Drop the photos in this folder as they are: any file names, JPG / PNG / HEIC / WEBP,
full size. No renaming or sorting needed.

Claude will then:
  1. Look at each photo and work out what it shows (dish, fish, interior, etc.).
  2. Suggest where each one goes on the site, and list any photos it is unsure about.
  3. After you confirm, resize and compress them into public/photos/ and wire them in.

This folder is NOT uploaded to GitHub or the live site (see .gitignore).
Only the processed copies in public/photos/ go live.

Tip: if you know what something is (e.g. "sayadieh", "the terrace"), putting that in
the file name helps, but it is optional.
